## Done

- [x] **REPL `:cd` write-mode** — `:pin`/`:unpin` inside `:cd` publishes declarations into the entered package's `Globals` (monkey-patching; visible to every importer in the session engine). Cells of package vars are aliased into the repl scope at `Pin` (after `EnsureReady`) so `x = v` writes through OpSetGlobal's shared cell; `x := v` reuses or shadows into a published cell (also how bound non-cell members get patched); func/type decls bind their materialized value into both scopes (one identity — reload eviction skips them — with `Pkg` retargeted to the entered package so patches survive `:cd -`); method decls graft onto the entered index's `Types[recv].Methods` (or onto a live published typedef for repl-declared receivers) and evict the cached typedef so the next access rebuilds the method set; the decl's repl-file import table is registered into the package (`graftScope`) so patched bodies resolve repl imports. `:unpin`/`:cd -`/`:cd` elsewhere decouple: written names stay in the package, borrowed repl names drop, and bindings shadowed by an alias are restored (the saved binding object itself, not a snapshot). `:ls` marks published decls `patch`; `:cd` shows `[pin]`. Caveats kept from the plan: package objects are shared, so patches are session-wide; a package var keeps its declared type (`Typ` coercion on the shared cell), and consts stay read-only.

- [x] **Task-runner example**: `examples/task-run` — a mage/go-task-style runner on minigo ([docs/sketch/plan-task-runner.md](../sketch/plan-task-runner.md)). Taskfiles are Go files (`//go:build task`); exported `func()`/`func() error`/`func(...string)` decls are tasks; the bound `task` package provides `Deps`/`SerialDeps`/`F`/`Sh`/`Run`/`RunIn`/`Output`/`Target`/`Log`/`Env`. `Deps` runs deps in parallel on spawned goroutines (a shared `depStates` map gives both modes dedup and ancestry-based cycle detection; a dep error fails the run); `SerialDeps` keeps serial ordering. Follow-ups are in the plan file (task arg typing, discovery, namespaces).

- [x] **REPL + CLI subcommands**: `engine.NewREPL()` gives a persistent session — declarations accumulate, `:=`/`var`/`const` names hoist to package-global cells, a trailing expression becomes the value (`x := e` re-declaration updates rather than shadows — documented divergence). `cmd/minigo` gained `run --entry F` and `repl` subcommands; the `minigo <ref> [func]` shorthand is unchanged.

- [x] **REPL multi-line input**: `minigo.IncompleteInput` tokenizes the pending fragment — an open `()`/`[]`/`{}` group, or a line ending where Go inserts no semicolon (trailing operator, comma, dot), reads as a continuation, and the `minigo repl` loop accumulates under a `.. ` prompt until the fragment completes. `} else {` keeps Go's same-line rule; comment-only and unterminated-token lines evaluate immediately so their errors surface instead of waiting. Leftover: a mistyped line that happens to look incomplete (e.g. a trailing `+`) waits silently — no abort-fragment command yet.
- [x] **REPL directory imports**: `import "./dir"` (also `../dir`, `/abs/dir`) — illegal in real Go source but natural at a prompt launched from a project root — resolves eagerly against the engine's start directory: a typo fails the import line itself, and the recorded spec binds the package's declared name (`import "./oddname"` binds `oddpkg`) instead of the path basename, which may not even be a valid identifier. Explicit aliases and dot/blank forms work unchanged; the `Load` hook of a dir-form `ImportRef` routes through `loadDir`. Echo cleanup in the same pass: only an input ending in an expression prints its value (declarations and `:=`/`var`/`const` stay silent — no more `(0x0,0x0)` noise), and multi-return results render as tuples (`fmt.Println` → `(6, <nil>)`) instead of a raw box.
- [x] **`minigo vet`** (plan §16): `Engine.Vet(ctx, ref)` lists call sites `pkgAlias.Sym(...)` whose target declaration is a stub member (body is exactly `panic("minigo intrinsic")`) and whose `SymbolID` is neither a registered special form nor a bound host symbol — the failure they would hit at run time, reported statically with file:line positions. `minigo vet <ref>` prints findings and exits nonzero; `--special import/path.Sym` declares intercepted symbols for CLI use (embedding apps get theirs from `RegisterSpecial`/`Bind` for free). Dot imports are invisible to the checker.
- [x] **`gen-intrinsics` subcommand** (plan §15): `minigo gen-intrinsics -output <dir> <pkg>...` emits `<path>/install.go` with `func Bind(e *minigo.Engine)` registering every exported member: non-generic functions via the new `minigo.WrapFunc` reflect adapter (marshal-by-copy, trailing `error` result unwraps to the call's error, multi-results become `*runtime.Tuple`), vars/consts as `minigo.ValueOf` snapshots, types as boxed `reflect.Type`. Generic functions and methods are skipped. `ValueOf` is the public marshal helper — note `runtime.Value` is an `any` alias, so it switches on concrete runtime types explicitly.

- [x] **`docgen` on minigo**: `examples/docgen/loader.go` now evaluates the patterns DSL with minigo — `NewEngine(dir-of-config)` + `LoadFile` + `EnsureReady` + `Globals.Get("Patterns")` + `Result.As`, and `Fn` references arrive as `*runtime.Function`/`*runtime.BoundMethod` whose `Pkg.Path` is already the import path (v1 needed a ModuleDir/ModulePath dance). docgen has no v1 `minigo` dependency left; `examples/minigo` is the last v1 consumer. Notes: `LoadPatternsFromSource` (string-eval) was dropped — minigo entries are file-oriented; method `Function.Name` reads `"Type.Method"` with `Recv` now stamped at materialize time, and `(*T).M` spelling is rebuilt from `Recv`/`Name`+`PtrRecv`. See docs/sketch/plan-minigo-vm.md rounds 15-16.
