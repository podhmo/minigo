# TODO — convert-define

The `examples/convert-define` DSL/codegen example and its supporting machinery.

## Open

- [ ] **`convert-define`: element-wise conversion through generic instantiations** (`check04-generic-instantiation`, PR #132 review): `type SrcList List[int]` unwraps only as far as the instantiation — `Unwrap`/`SymbolID` cannot resolve `List[int]`, so the walk stops at the parametric spec `[]T` and the real element types are invisible. Both sides warn (`no conversion covers ... (generic instantiation)`) and keep the honest raw assignment instead of leafCast's uncompilable `DstList(src)`; a written instantiation (`List[int]`->`List[int64]`) already warned through leaf-mismatch. Real support needs type-argument substitution (instantiating the spec `[]T` as `[]int`), which the inspect layer deliberately does not do.
