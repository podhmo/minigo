Intrinsic stdlib bindings, GOROOT source interpretation, the script/host value boundary, and engine restriction modes.

- [x] **`AllowedRoots` option**: `WithAllowedRoots(roots...)` restricts located directories to the given roots (checked in `Locate`/`LocateDir`).
- [x] **Stdlib acceleration**: intrinsic bindings for fmt/errors/strings/strconv/sort/slices/maps/os/time are installed into every engine via `Bind`; host values are boxed as `*runtime.GoValue` with reflective method dispatch.

- [x] **Restricted-mode host-surface policy**: `WithHostPolicy(func(path, sym string) bool)` filters every `Bind` symbol (stdlib intrinsics included). Per-call path checks landed: `resolve.BuildConfig.CheckPath` resolves symlinks through the nearest existing ancestor, and every filesystem intrinsic routes through `Engine.fsPath` (virtual-cwd anchor + roots check), so file I/O is bound but confined. `os/exec` and the env/argv/stdio surface bind only when unrestricted (a spawned process escapes path confinement); `os.Exit` always traps; `WithOutput(w)` routes fmt/print output. - [x] **Virtual cwd + `os.Chdir`/`os.Getwd`**: `WithWorkingDir(dir)`/`Engine.WorkingDir()` give each engine its own cwd (defaults to `NewEngine`'s startDir, inherited by sessions); script `os.Chdir` moves it without touching the host process — `host.Getwd` still reports the real one. `filepath.Abs`/`Rel`, relative fs paths, and `exec.Cmd.Dir` all anchor there.
- [x] **Host-struct fields on `*runtime.GoValue`**: `selectMember`/`setField` probe exported struct fields through pointer chains (get and set), falling back to the reflective method set; `toReflectValue` marshals writes/method args element-wise for slices/maps with assignable-or-convertible scalars, so `cmd.Dir = "sub"`, `cmd.Stdout = os.Stdout`, `f.Write("text")` work on `*exec.Cmd`/`*os.File`.
