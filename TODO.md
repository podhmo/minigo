- [ ] **nested `UnmarshalJSON` receives the re-encoded literal, not the original byte span** (documented approximation in #715): below the top-level pointer the decoder hands `json.Marshal(dec)` output to the script method, so a method that reads the exact bytes (whitespace, number spelling like `1e2`, escaping, duplicate keys) diverges from gc, which passes the input's original span.
- [ ] **`Unmarshal` into `**T` does not allocate the pointer chain** (residual gap of the #715 dispatch): gc's `indirect()` walks and allocates each level, so `var p **U; json.Unmarshal([]byte("q"), &p)` lands `p == &U{"q!"}`. The bound decoder hands the script method a nil `*U`, which panics `invalid memory address or nil pointer dereference` inside the method.
- [ ] **bound `encoding/json` does not export the `Unmarshaler`/`Marshaler` interface types** (residual gap of #715): `var i json.Unmarshaler = new(U)` traps `undefined: json.Unmarshaler`, so gc's path of dispatching through an interface value that holds an Unmarshaler (`json.Unmarshal(data, &i)`) is unreachable — with the type bound, an interface-holding target should also route into `UnmarshalJSON` (gc prints the method's result `"w"!`).
- [ ] **an anonymous embedded field's `UnmarshalJSON`/`MarshalJSON` is not called** (residual gap of #715): gc flattens anonymous embeds and hands the WHOLE parent literal to the embedded method — `type HasEmbed struct{ Money }` with `{"Money":"10"}` calls `Money.UnmarshalJSON({"Money":"10"})`. The bound decoder walks the embed's fields by shape and never probes the promoted method (verified: field stays empty).
- [ ] **a nested `UnmarshalJSON` error always preempts the input-order first error** (residual gap of #715): gc reports the FIRST error in input order — for `{"a":"notint","b":"x"}` into `struct{ A int; B Fail }` it reports the `a` type error even though `b`'s method returns `custom fail`. The bound decoder's `ectx.callErr` wins unconditionally, so it reports `custom fail`.
- [ ] **`fmt` does not emit gc's `%!v(PANIC=Error method: ...)` marker** (residual gap of the #714 fmt side): when a value's `Error()`/`String()` panics, gc prints `%!v(PANIC=Error method: <panic text>)`; the bound fmt swallows the panic silently and prints the plain value dump (`{}` for an empty struct).
- [ ] **`Member`/`MethodSetOf` may over-match on unnamed container types** (mechanism observed during #715, unverified as a divergence): on `[]Upper`/`map[string]Upper` the member walk borrows the ELEMENT type's `UnmarshalJSON`; the jsonShape call site is gated by `td.Name != ""`, but the same `IfaceMember`/`MethodSetOf` walks run in the fmt probes and other dispatch paths — audit whether the vm-level member walk itself needs the named-type guard.
- [ ] **`panic while printing panic value` folds inner panic names to `runtime.errorString`** (documented approximation in #714, error text only): gc names the inner panic's concrete type (`boundsError`, …); the marker maps every `*RuntimeError` to `runtime.errorString`.
- [ ] **difffuzz cannot pin unrecovered/fatal panics** (harness gap noted during #714): a case whose expectation is `runErr != nil` fails the run's exit-status check, so fatal-path divergences (`panic while printing panic value`, uncaught panics) can only be covered by `minigo_test`-style host tests, not `testdata/difffuzz` pins. Extending the harness (e.g. a `want.err` oracle) would let them pin.
- [ ] **`--src strings` traps in `strings.Index`** (found in [docs/sketch/experiment-oapi-codegen-perf.md](./docs/sketch/experiment-oapi-codegen-perf.md)): `minigo run --src strings` on `strings.Index("chicken", "ken")` traps `cannot use int64 as int` at the `stringslite.Index(s, substr)` return. `--src sort` fails differently: `sort.Slice` reaches `internal/reflectlite` (`unsafe.Pointer` undefined).
- [ ] **host `any` parameters run a struct's niladic methods** ([docs/sketch/experiment-oapi-codegen-perf.md](./docs/sketch/experiment-oapi-codegen-perf.md), step 5): `structDataHost` invokes every niladic exported method when a script struct crosses any host `any` parameter. That serves text/template's `evalField`, but it is SILENT for side-effecting methods. `sync.Pool.Put`/`New` are now opaque; `sync.Map.Store`/`LoadOrStore`/`Swap`, `atomic.Value.Store`/`Swap` and `context.WithValue` still marshal. A general "containers keep script values opaque" rule would beat a per-method list.
- [ ] **source text/template: field access on a parenthesized pipeline panics** ([docs/sketch/experiment-oapi-codegen-perf.md](./docs/sketch/experiment-oapi-codegen-perf.md)): `{{(index .Items 1).Name}}` under `--src text/template` panics with `reflect: call of reflect.Value.Field on struct Value` in exec's `evalField`. Native prints the field. The chain node's receiver reaches `evalField` as a bad minireflect value.
- [ ] **html/template from source cannot run** ([docs/sketch/experiment-oapi-codegen-perf.md](./docs/sketch/experiment-oapi-codegen-perf.md)): with `--src html/template,text/template,encoding/json,encoding/hex,encoding/base64,encoding/base32,slices,maps` it stops at `bytes.IndexAny` (unbound); adding `--src bytes` stops at `bytealg.IndexByte` ("cannot use int64 as int", like `--src strings`).
- [ ] **32-bit targets do not build** (found while checking the `goroutineID` fallback): `GOOS=linux GOARCH=arm go vet ./vm` fails in `minireflect/rvalue.go`. Constants such as `uintptr(1) << 48` and `0x6d696e69676f` overflow a 32-bit `uintptr`. Either size them per `unsafe.Sizeof(uintptr(0))` or declare 64-bit only with a build constraint and say so in the README.
- [ ] **run oapi-codegen-examples periodically** ([docs/sketch/experiment-oapi-codegen-perf.md](./docs/sketch/experiment-oapi-codegen-perf.md), step 0): #662 and #675 each broke oapi-codegen (all 53 lines, then 3), and the difffuzz suite caught neither. A scheduled realworld `oapi-codegen-examples` run (~5 min) would.
- [ ] **`sync.Pool.Put` of a script struct value aliases it** (#699 review, also on main): `p.Put(s); s.N = 2; p.Get().(S).N` prints 2 where gc prints 1. The struct crosses opaque now, but a value-typed struct must be copied at Put like Go's interface boxing.
- [ ] **copying a host-backed value aliases it** (#699 review follow-up, also on main): `var a bytes.Buffer; b := a; b.WriteString("x")` prints `1 1` where gc prints `0 1` (`strings.Builder` too). A `HostNew` typedef's zero value is a pointer-shaped `GoValue` box, and assignment copies the box, not the host struct. Copy the host value on assignment (reflect.New + Set), or document host-backed types as reference-like.
- [ ] **a named-int index loses `s[i].N++` on a struct slice element** (#699 review, also on main): with `type I int`, `s[i].N++` on `[]S` leaves `s[0].N` unchanged (gc: incremented), while `m[i][0]++` on a map works. The `I`-tagged index likely misses the element ref path.
- [ ] **inferring a type parameter from a host error value traps `undefined: T`** (found while writing `generic_infer_cache`, also on main): with `func kind[T any](x T) string`, both `var err error = errors.New("e"); kind(err)` and `for _, v := range []any{1, errors.New("e")} { kind(v) }` (on the error) trap where gc binds T=error / T=any. `var v any = errors.New("e"); kind(v)` works. The static type seems to be dropped for these call sites, and a host error value yields no typedef of its own.
- [ ] **Bound `strconv.IntSize` is missing** ([docs/sketch/experiment-oapi-template-cache.md](./docs/sketch/experiment-oapi-template-cache.md#minimum-reproductions)): `fmt.Println(strconv.IntSize)` traps `undefined: strconv.IntSize`; native prints `64` on arm64. Source base64 decoding also reaches it through JSON byte-slice decoding. Bind the architecture-appropriate constant without replacing the rest of the bound package.
- [ ] **JSON-decoded byte slices lose assignment type information** ([docs/sketch/experiment-oapi-template-cache.md](./docs/sketch/experiment-oapi-template-cache.md#minimum-reproductions)): with `encoding/json` and its supporting packages interpreted, `json.Unmarshal` into a `Text []byte` field succeeds after a harness-only IntSize workaround, but `state{Text: decoded.Text}` traps `cannot use slice as []byte`; native prints `a` for `{"Text":"YQ=="}`. Preserve the decoded slice's element/type metadata at the reflection-to-script boundary.
