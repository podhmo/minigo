- [ ] **`Engine.Call`: unbox host container args** (bug found by the minigo-generate spike, #390): a `[]string` passed as a Call arg arrives as the raw Go slice and the callee's param coerce traps `cannot use []string as []string` — the shape check wants a `*runtime.Slice`. Scalars cross fine; only containers don't. Either `Call` should run args through `goValueOf` (what reflect-call results already get) or the boundary needs a documented conversion. Workaround in place: callers box args as `&runtime.Slice{Elems:}` (examples/minigo-generate).
