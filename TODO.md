- [ ] **pre-seeded source replacements can bypass package initialization** ([#1454](https://github.com/podhmo/minigo/pull/1454)): a direct call can receive the pre-seeded replacement before the target package's vars and `init` run. The initialization wrapper still has to let calls reached during initialization proceed without deadlocking.
- [ ] **`any` host marshaling loses script structs in Go replacements** ([#1454](https://github.com/podhmo/minigo/pull/1454)): a Go replacement taking `any` can receive a display string instead of the original script struct, breaking round-trip-shaped fakes. Design an opaque/pass-through representation at the host marshaling boundary rather than patching `ReplaceSourceFunc` locally.
- [ ] **source replacements cannot be refreshed after a source signature edit** ([#1454](https://github.com/podhmo/minigo/pull/1454)): load-time validation of an inherited old replacement can fail before `ReplaceSourceFunc` has a chance to install the new one. Separate registration from load-time validation or add an explicit removal/refresh API.
